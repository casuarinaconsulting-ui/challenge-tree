Add it as a button on Wix

  1. Download the version you want (the pill button is the most "button-like").
  2. In the Wix Editor: Add → Image → upload the PNG.
  3. Select the image → click the Link icon → Web Address → paste https://challenge-tree.vercel.app
  4. Set it to open in a new tab, and resize to taste.
